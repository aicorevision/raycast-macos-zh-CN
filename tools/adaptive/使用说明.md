# Raycast macOS 一键汉化使用说明

## 安装前

- 使用 Apple Silicon Mac，并将 Raycast 官方版放在「应用程序」文件夹。至少打开过一次官方版。[Raycast 官网](https://www.raycast.com/)
- 当前实机验收版本是 Raycast 2.14.0.0。安装器会读取本机版本和资源结构，通过校验后开始替换。
- 如果已使用其他汉化工具，先用对应的恢复工具还原官方版。已经使用本工具完成安装的版本可以重复双击，安装器会核验并显示已安装。

## 一键安装

1. 打开 [GitHub Releases](https://github.com/aicorevision/raycast-macos-zh-CN/releases/latest)，下载附件 **raycast-zh-cn-one-click-macos-arm64.zip**。
2. 在「下载」中解压 ZIP，打开 **Raycast 中文一键安装** 文件夹。请将文件夹内的脚本和 tools 子目录一起保留。
3. 双击 **安装汉化.command**。终端会显示检测到的 Raycast 版本。扫描完成后，它会自动退出 Raycast、备份并写入汉化资源，然后重新打开。
4. 在 Raycast 中检查中文搜索框。输入「扩展商店」，可查看已覆盖的扩展简介和部分命令说明。

发布包内置 Apple Silicon 版 Node.js 和 Acorn，解压后即可使用。汉化资源由本机现有的官方 Raycast 生成。

## 汉化范围

主搜索、设置、扩展商店界面、部分商店扩展的说明和命令。已补充 2.14 的「建议快捷键」「区域」「片段导入」「浏览器配对」和「Raycast MCP 服务器」等入口与说明。菜单栏、部分扩展内部页面和动态数据仍可能显示英文。扩展本身按正常方式通过 Raycast 商店安装。

## 恢复官方原版

双击 **恢复原版.command**。工具会找到当前版本的安装记录和本地备份，检查文件后还原并重启 Raycast。恢复时会验证官方签名。备份位于「资源库 → Application Support → Raycast-Chinese-Patch」。

## 更新 Raycast 后

可先运行恢复，再按正常方式更新 Raycast。更新完成后，重新双击 **安装汉化.command**，工具会读取新版本并重新生成对应补丁。新版新增的英文需要复核后补入词库，建议使用 GitHub 上最新的安装包。应用结构变化较大时，工具会提示需要适配。

## 常见问题

**双击没有打开终端。** 在终端中输入 **/bin/bash** 和一个空格，将「安装汉化.command」拖入同一窗口后按回车。恢复脚本也支持这种方式。

**提示找不到 Raycast。** 将官方 Raycast.app 放在「应用程序」中。自定义安装位置可在终端执行以下命令。

    ./安装汉化.command --app "/实际位置/Raycast.app"

**汉化后 Raycast 无法启动。** 安装器会尝试还原原版。也可双击「恢复原版.command」。如果恢复工具提示应用文件已被更新或再次修改，重新安装 Raycast 官方版即可恢复应用文件。

**账户、笔记和剪贴板数据。** 安装器的替换和备份范围是应用包中的界面资源，Raycast 的用户数据由应用自行管理。

**如何校验下载。** 发布页提供同名的 .sha256 文件。将它和 ZIP 放在同一个文件夹，在该目录执行以下命令。

    shasum -a 256 -c raycast-zh-cn-one-click-macos-arm64.zip.sha256
